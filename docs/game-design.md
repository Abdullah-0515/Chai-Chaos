# Chai Chaos: Pakistani Brainrot Game Design

Oct 31, 2026 · @RANA ABDULLAH

## Pitch

**Chai Chaos** is a collect-and-earn tycoon set in a loud Pakistani bazaar. Silly desi "brainrot" creatures walk down the market lane, you buy them with rupees, park them at your haveli, and they earn more rupees every second so you can buy rarer ones.

Tone rules: food, rickshaws, cricket, load shedding, aunties and uncles are fair game. No real people, no religion, no politics, and no jokes that put down any city, province or group. Every joke should be something a Pakistani kid would laugh at with their family.

## Core loop

One loop takes about 30 seconds, and every pass makes you a bit richer.

1. A brainrot spawns at the top of **Bazaar Lane** and walks slowly toward the end.
2. You run up and press **E** to buy it with rupees (Rs). If you are too slow, it walks off and disappears.
3. It walks to your **haveli** and stands on an empty plot.
4. Each brainrot earns Rs per second. You walk over your **galla** (cash box) to collect.
5. Spend rupees on rarer brainrots and on more plots, then repeat.
6. Sell an old brainrot for half its price to free a plot for a better one.

## Map

The map is one big bazaar with a lane down the middle and eight havelis (player bases) on the sides.

- **Bazaar Lane:** a long conveyor-style path where brainrots walk from the Spawn Gate to the Chowk (town square). Chai stalls, fruit carts and string lights line it.
- **Havelis:** each player gets a two-floor haveli with 10 plots, a galla and a rooftop. Plots unlock with rupees.
- **Chowk:** the town square at the end of the lane with a fountain, a leaderboard and the sell stall.
- **Rooftop:** a quiet spot with kites in the sky, used for a later kite-flying minigame.

## Progression and events

- **Plots:** start with 3 plots and unlock up to 10 for Rs 500, 2,000, 5,000 and so on.
- **Rebirth ("Naya Safar"):** at Rs 1,000,000 you reset your rupees and plots for a permanent +50% income multiplier and a new haveli colour.
- **Daily chai:** log in each day for a free brainrot or a rupee boost.
- **Events:** Eid-style festival nights, Basant kite nights with flying brainrots, and Cricket Mania weekends with a Sixer Sher spawn boost. Event content stays friendly to everyone.
- **Collection book:** a Pokédex-style page that fills in as you discover each brainrot.

## Monetization ideas

Keep it fair, because most players are kids.

- **2x Cash** game pass.
- **Extra plots** game pass.
- **Lucky spawn** developer product: raises rare spawn odds for 10 minutes.
- **Cosmetics:** haveli skins, trails and hats, with no pay-to-win advantage.
- Never sell guaranteed top-rarity brainrots directly.

## How to build the characters

You do not need to be an artist. Start with blocky shapes, make the game fun, then make the models nicer later.

**Option 1: build with parts in Studio (easiest, free)**

1. In Roblox Studio, open the **Model** tab and insert Parts: Block, Sphere, Cylinder and Wedge.
2. Build the character from simple shapes. For example, Samosa Supremo is one Wedge (golden brown) plus two small black Blocks for sunglasses.
3. Use **Color** and **Material** (try SmoothPlastic, Neon for glowing eyes, and Fabric for clothes).
4. Select all its parts, right-click and choose **Group** (Ctrl+G) to make a Model. Name it exactly as in the script, like `SamosaSupremo`.
5. Pick the biggest part, set it as the Model's **PrimaryPart**, and add a **WeldConstraint** from every other part to it so they move together. Uncheck **Anchored** on all parts except while you are building.
6. Drag the Model into the `Brainrots` folder in ServerStorage.

**Option 2: make them in Blender (better looking, free)**

1. Model the character in [Blender](https://www.blender.org), keeping it under about 10,000 triangles.
2. Paint or colour it, then export as **.fbx** or **.obj**.
3. In Studio, use **File > Import 3D** to bring it in as a MeshPart, then group and name it like above.

**Option 3: start from the Toolbox**

Search the Creator Store for free food or animal models and reshape or recolour them. Only use ones marked free to use, and check them for hidden scripts before you add them.

**Make them feel like brainrots**

- **Face:** add a **Decal** with a funny face on the front part. You can draw one in any paint app and upload it.
- **Catchphrase:** add a **BillboardGui** with a TextLabel above the head, and set its text to the joke from the table.
- **Sound:** upload a short funny sound (a honk, a "pon pon", a chai slurp) and play it when someone buys the brainrot.
- **Movement:** make them bob up and down or spin slowly with a TweenService loop, which looks great and needs no animation work.
- **Rarity glow:** add a **Highlight** or a **ParticleEmitter** with a colour per rarity, such as grey for Common, blue for Rare, purple for Epic, gold for Legendary and rainbow for Mythic.

A good order is to build 3 blocky Commons first, get the buy and steal loop working, and then add one new character at a time.

## Build steps and starter script

1. Install Roblox Studio and create a new Baseplate place.
2. Build a long Part for Bazaar Lane and a Part named `SpawnGate` at its start. Make a folder `Brainrots` in ServerStorage with one simple Model per character (a coloured block is fine at first).
3. Add a Folder named `Havelis` in Workspace with a Part named `Plot1`, `Plot2` and so on.
4. In ServerScriptService, add a Script with the code below. It spawns brainrots, lets players buy them with a ProximityPrompt and pays rupees every second.

```lua
local Players = game:GetService("Players")
local ServerStorage = game:GetService("ServerStorage")
local TweenService = game:GetService("TweenService")

local BRAINROTS = {
	{ name = "GolGappaGhostu", rarity = "Common", price = 25, income = 1, weight = 60 },
	{ name = "SamosaSupremo", rarity = "Common", price = 50, income = 2, weight = 30 },
	{ name = "RickshawRaptor", rarity = "Uncommon", price = 600, income = 18, weight = 10 },
}

local spawnGate = workspace:WaitForChild("SpawnGate")
local endPoint = workspace:WaitForChild("LaneEnd")

-- set up cash for each player
Players.PlayerAdded:Connect(function(player)
	local stats = Instance.new("Folder")
	stats.Name = "leaderstats"
	stats.Parent = player
	local cash = Instance.new("IntValue")
	cash.Name = "Rupees"
	cash.Value = 100
	cash.Parent = stats
end)

local function pickBrainrot()
	local total = 0
	for _, b in BRAINROTS do total += b.weight end
	local roll = math.random() * total
	for _, b in BRAINROTS do
		roll -= b.weight
		if roll <= 0 then return b end
	end
	return BRAINROTS[1]
end

local function startEarning(player, data, model)
	task.spawn(function()
		while model.Parent and player.Parent do
			task.wait(1)
			player.leaderstats.Rupees.Value += data.income
		end
	end)
end

local function spawnBrainrot()
	local data = pickBrainrot()
	local template = ServerStorage.Brainrots:FindFirstChild(data.name)
	if not template then return end
	local model = template:Clone()
	model:PivotTo(spawnGate.CFrame + Vector3.new(0, 3, 0))
	model.Parent = workspace

	local prompt = Instance.new("ProximityPrompt")
	prompt.ActionText = "Buy Rs " .. data.price
	prompt.ObjectText = data.name .. " (" .. data.rarity .. ")"
	prompt.Parent = model.PrimaryPart or model:FindFirstChildWhichIsA("BasePart")

	prompt.Triggered:Connect(function(player)
		local cash = player.leaderstats.Rupees
		if cash.Value < data.price then return end
		cash.Value -= data.price
		prompt:Destroy()
		-- TODO: move model to the player's next free plot
		startEarning(player, data, model)
	end)

	-- walk down the lane, then vanish if nobody bought it
	local tween = TweenService:Create(model.PrimaryPart, TweenInfo.new(20, Enum.EasingStyle.Linear), { CFrame = endPoint.CFrame + Vector3.new(0, 3, 0) })
	tween:Play()
	tween.Completed:Connect(function()
		if prompt.Parent then model:Destroy() end
	end)
end

while true do
	task.wait(5)
	spawnBrainrot()
end
```

This is a first draft that I have not run in Studio. Next steps are plots, saving with DataStore, a galla UI, and the 12 full characters.

## Stealing mechanic

Players can steal brainrots from each other's havelis, which makes the game a tense race. It stays fair with a lock, a cooldown and a way to get your brainrot back.

- **Steal:** hold E on another player's brainrot for 1.5 seconds. The brainrot then rides on the thief's back.
- **Escape:** the thief must run to their own haveli's door to keep it. If the thief falls off the map, dies or leaves, the brainrot goes back to its owner.
- **Alert:** the owner gets a loud "Chor! Chor!" message with the thief's name, and the stolen brainrot's pop-up shows its catchphrase in panic.
- **Lock ("Taala"):** the owner presses a button to lock their haveli for 30 seconds. Locks then have a 60 second cooldown, so you cannot stay locked forever. Locked havelis cannot be robbed.
- **Cooldown:** a thief can steal once every 15 seconds, and the same haveli cannot be targeted twice in a row within 2 minutes.
- **Get it back:** thieves are marked on the owner's screen while carrying, and tagging the thief (a bonk with a chappal tool) makes them drop the brainrot.
- **Protection:** new players get 3 minutes of steal protection, and only brainrots worth up to Rs 8,000 can be stolen at first, so the top rarities stay safe until a rebirth.
- **Safe slots:** two plots per haveli are "Locker" plots that cannot be stolen from.

Starter script to add to the same Script (not run in Studio yet, so test and adjust names):

```lua
local STEAL_COOLDOWN = 15
local LOCK_TIME = 30
local LOCK_COOLDOWN = 60

local lastSteal = {}   -- [player] = os.clock()
local carrying = {}    -- [player] = {model=..., owner=..., data=...}

local function returnToOwner(thief)
	local info = carrying[thief]
	if not info then return end
	carrying[thief] = nil
	local weld = info.model:FindFirstChild("CarryWeld", true)
	if weld then weld:Destroy() end
	if info.owner.Parent then
		-- TODO: move model back to the owner's plot
		startEarning(info.owner, info.data, info.model)
		info.model:SetAttribute("Owner", info.owner.UserId)
	else
		info.model:Destroy()
	end
end

local function completeSteal(thief)
	local info = carrying[thief]
	if not info then return end
	carrying[thief] = nil
	info.model:SetAttribute("Owner", thief.UserId)
	-- TODO: move model to the thief's next free plot
	startEarning(thief, info.data, info.model)
end

local function addStealPrompt(model, owner, data)
	local part = model.PrimaryPart or model:FindFirstChildWhichIsA("BasePart")
	local prompt = Instance.new("ProximityPrompt")
	prompt.ActionText = "Steal"
	prompt.ObjectText = data.name
	prompt.HoldDuration = 1.5
	prompt.RequiresLineOfSight = false
	prompt.Parent = part

	prompt.Triggered:Connect(function(thief)
		if thief == owner or carrying[thief] then return end
		if (owner:GetAttribute("LockedUntil") or 0) > os.time() then return end
		if os.clock() - (lastSteal[thief] or -999) < STEAL_COOLDOWN then return end
		local root = thief.Character and thief.Character:FindFirstChild("HumanoidRootPart")
		if not root then return end

		lastSteal[thief] = os.clock()
		carrying[thief] = { model = model, owner = owner, data = data }
		model:SetAttribute("Owner", 0)  -- stops the owner earning from it
		prompt:Destroy()

		model:PivotTo(root.CFrame * CFrame.new(0, 0, 2))
		local weld = Instance.new("WeldConstraint")
		weld.Name = "CarryWeld"
		weld.Part0 = root
		weld.Part1 = part
		weld.Parent = part

		-- alert the owner (needs a RemoteEvent called StealAlert in ReplicatedStorage)
		game.ReplicatedStorage.StealAlert:FireClient(owner, "Chor! Chor! " .. thief.Name .. " stole " .. data.name)

		-- thief dies or leaves: brainrot goes back
		local humanoid = thief.Character:FindFirstChildOfClass("Humanoid")
		humanoid.Died:Connect(function() returnToOwner(thief) end)
	end)
end

Players.PlayerRemoving:Connect(returnToOwner)

-- Lock button: fire a RemoteEvent "LockHaveli" from a GUI button
game.ReplicatedStorage.LockHaveli.OnServerEvent:Connect(function(player)
	if (player:GetAttribute("LockReadyAt") or 0) > os.time() then return end
	player:SetAttribute("LockedUntil", os.time() + LOCK_TIME)
	player:SetAttribute("LockReadyAt", os.time() + LOCK_TIME + LOCK_COOLDOWN)
end)

-- Each haveli door: a Part named "HaveliDoor" with an Owner attribute set when a player claims it
for _, door in workspace.Havelis:GetDescendants() do
	if door.Name == "HaveliDoor" then
		door.Touched:Connect(function(hit)
			local thief = Players:GetPlayerFromCharacter(hit.Parent)
			if thief and carrying[thief] and door:GetAttribute("Owner") == thief.UserId then
				completeSteal(thief)
			end
		end)
	end
end
```

In the buy function, call `addStealPrompt(model, player, data)` right after `startEarning`, so every owned brainrot can be stolen.
